# IT0043-AI-CSS-Portfolio

Welcome to My Portfolio! This repository is built with HTML and CSS to demonstrate design tokens, keyboard accessibility, and an empirical evaluation against an AI-generated rival stylesheet.

## Project Structure
- `css/style.css`: Hand-crafted stylesheet built with CSS custom properties.
- `ai-style.css`: Untouched AI-generated dark mode stylesheet.
- `index.html`, `about.html`, `projects.html`, `contact.html`: Multi-page portfolio.
